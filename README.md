# Пакетная установка программ

Программа с окном для быстрой установки нужного софта на чистую Windows 10/11.
Отмечаете галочками, что нужно, жмёте «Установить выбранные» и ждёте.

## Как запустить

1. Скопируйте папку `batch-installer` на новый компьютер (флешка, облако).
2. Дважды щёлкните `Install.bat` и подтвердите запрос прав администратора.

Больше ничего ставить не нужно: PowerShell и WPF уже есть в Windows.

## Что умеет

- Слева поиск и список категорий (клик по категории показывает только её программы). В центре список программ, клик по строке ставит или снимает отметку. Справа плитки «Все», «Ничего», «По умолчанию», «Установленные», а у каждой категории в списке есть ссылка «выбрать / снять».
- Поиск по названию, описанию и id.
- **Режим установки** (плитки справа вверху). «Тихая»: программы ставятся без окон и вопросов. «С мастером»: у каждой открывается её обычный мастер установки.
- Прогресс-бар, статус у каждой программы и подробный лог. Лог также сохраняется в папку `logs\`.
- «Установленные»: находит уже установленные программы и снимает галочки с того, что уже стоит.
- «Сохранить выбор»: запоминает ваши галочки в `selection.json`, при следующем запуске они восстановятся.
- «Отмена»: текущая программа доустановится, остальные пропустятся.
- Если программа уже установлена, это не считается ошибкой. Если нужна перезагрузка, в конце будет сообщение.

## Как устроено и почему так

- **PowerShell + WPF**: работает на любой Windows 10/11 без установки .NET SDK, Python и без компиляции. Скрипт можно открыть и поправить в Блокноте.
- **winget** (встроенный менеджер пакетов Windows) скачивает актуальные версии с официальных источников и сам знает ключи тихой установки для каждой программы. Поэтому в списке не нужно хранить ссылки и ключи.
- Для программ, которых нет в winget, можно указать прямую ссылку или свой установщик с ключами (см. ниже).

## Как изменить список программ

Список лежит в `apps.json` (кнопка «Изменить список» открывает его в Блокноте). После правки перезапустите программу.
Сохраняйте файл в кодировке UTF-8.

### Программа из winget

```json
{ "name": "Telegram", "category": "Общение", "source": "winget", "id": "Telegram.TelegramDesktop", "checked": true, "description": "Мессенджер" }
```

Чтобы узнать id, выполните в терминале `winget search telegram` и возьмите значение из колонки «Id».

| Поле | Значение |
|---|---|
| `name` | Название в списке |
| `category` | Группа (категория) |
| `source` | `winget`, `url` или `local` |
| `id` | Id пакета winget |
| `checked` | Отмечена ли по умолчанию |
| `description` | Короткое описание |
| `extraArgs` | Необязательно. Доп. ключи winget, например `"--scope machine"` или `"--override \"/VERYSILENT\""` |
| `wingetSource` | Необязательно. `msstore` для программ из Microsoft Store (по умолчанию `winget`) |

### Установщик по прямой ссылке

```json
{ "name": "Моя программа", "category": "Прочее", "source": "url",
  "url": "https://example.com/setup.exe", "silentArgs": "/S", "normalArgs": "", "checked": false }
```

Файл скачивается во временную папку и запускается с `silentArgs` (тихо) или `normalArgs` (обычно).

Если у программы ссылка меняется с каждой версией, добавьте `urlPage` (страница загрузки) и `urlPattern` (регулярное выражение для ссылки). Тогда установщик сам найдёт свежую версию на странице, а `url` останется запасным вариантом. Так сделано для NVIDIA App.
Для `.msi` ключи можно не указывать: по умолчанию используется `/qn /norestart`.

### Свой установщик рядом со скриптом

```json
{ "name": "Драйвер принтера", "category": "Драйверы", "source": "local",
  "path": "installers\\printer.exe", "silentArgs": "/quiet", "checked": false }
```

Положите файл в папку `installers` рядом с `Installer.ps1`. Путь можно указать и абсолютный.

### Частые ключи тихой установки

| Тип установщика | Ключ |
|---|---|
| NSIS | `/S` |
| Inno Setup | `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` |
| InstallShield | `/s /v"/qn"` |
| MSI | `/qn /norestart` |

## Если что-то не работает

- **«winget не найден»**. На свежей Windows 10 установите «Установщик приложений» (App Installer) из Microsoft Store или с https://aka.ms/getwinget, либо сначала обновите систему через Центр обновления. На Windows 11 winget обычно уже есть.
- **«Не найдено в winget»**: проверьте id через `winget search`.
- **Ошибка у конкретной программы**: подробности в журнале справа в окне и в папке `logs\`.
